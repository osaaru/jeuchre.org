# jeuchre.org

Jeuchre is a card game that is the anti-euchre.

This repository currently contains the public website for jeuchre.org.

`site` is the Gatsby project used to build the site.
`devops` is the AWS CDK project used to deploy the infrastructure used to operate the site.
