# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be welcoming, no harassment, no personal attacks. The card game may
punish taking tricks; the community doesn't punish asking questions.

Instances of unacceptable behavior may be reported privately to the project steward via
GitHub (private vulnerability reporting or a direct message to the repository owner).
Maintainers will respect reporter privacy and act on reports in good faith.
